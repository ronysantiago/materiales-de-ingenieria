# Historial de cambios

## 0.3.0 — Laboratorio de Diagramas de Fase

- Nueva ruta `/herramientas/diagramas-de-fase/`.
- Prisma ternario A–B–C con proyección 3D interactiva, rotación y zoom.
- Superficies ilustrativas liquidus, solidus y solvus.
- Corte isotérmico horizontal sincronizado con una vista triangular 2D seleccionable.
- Modelos genéricos de solubilidad sólida completa, parcial y muy limitada.
- Recorridos de calentamiento/fusión y enfriamiento/solidificación.
- Estado de fases, temperaturas liquidus/solidus y fracción sólida interpolada de forma didáctica.
- Sección microestructural 2D esquemática de granos y líquido residual.
- Acceso desde la navegación principal y la portada.
- Prueba automatizada `npm run validate:ternary`.

**Alcance:** este módulo es un prototipo geométrico y pedagógico. No usa datos CALPHAD ni predice una aleación real o una microestructura física.
