## Reglas para recursos

- Utilizar nombres descriptivos.
- Incluir autor, procedencia, licencia o permiso de uso cuando corresponda.
- Para micrografías: registrar material, tratamiento, reactivo, técnica, aumento y escala si se conocen.
- Para modelos 3D: registrar formato, unidades, escala, fuente CAD, autor y limitaciones.
- Para datos: conservar el archivo original y documentar cualquier transformación.
