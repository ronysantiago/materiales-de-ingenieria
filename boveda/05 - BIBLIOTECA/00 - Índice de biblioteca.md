# Biblioteca científica

La biblioteca reúne las fuentes que sustentan el desarrollo académico. Cada obra o documento importante debe tener su propia nota bibliográfica cuando se utilice de forma recurrente.

## Registro mínimo de una fuente

Autor o entidad, año, título, edición o revista, editorial, DOI/ISBN/URL, páginas consultadas, fecha de consulta y notas sobre su utilidad.

## Criterio de calidad

Priorizar libros universitarios reconocidos, artículos revisados por pares, normas vigentes y documentación técnica primaria. Una página web general puede orientar, pero no debe ser la única fuente para una afirmación crítica de ingeniería.
